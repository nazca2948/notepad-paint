# メモ帳（手書き＋タイピング）PWA

シンプルなメモ帳アプリです。普段はタイピング、「✏ 手書き」ボタンで手書きレイヤーに切り替えて使えます。

## ファイル構成

```
index.html          本体
manifest.json        PWA設定（アプリ名・アイコン・色など）
sw.js                 オフラインキャッシュ用 Service Worker
icons/
  icon-192.png
  icon-512.png
  apple-touch-icon.png
```

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成する（例: `my-notepad`）
2. このzipの中身（`index.html` や `manifest.json` など）を**リポジトリ直下**にそのままアップロードする
   - フォルダごとではなく、中のファイル・フォルダを直接置いてください
3. リポジトリの **Settings → Pages** を開く
4. 「Build and deployment」の Source を **Deploy from a branch** にする
5. Branch を `main`（または該当のブランチ）、フォルダを `/(root)` にして Save
6. 数分待つと `https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになる

## インストール（アプリ化）方法

公開したURLをスマホやPCのブラウザで開くと：

- **Android Chrome**：アドレスバー付近に「インストール」の案内が出る、またはメニュー内の「アプリをインストール」
- **iPhone Safari**：共有ボタン → 「ホーム画面に追加」
- **Windows/Mac Chrome・Edge**：アドレスバー右側のインストールアイコン、またはメニューの「アプリをインストール」

これでネイティブアプリのように独立したウィンドウ／アイコンから起動できます。

## 保存について（重要）

メモの内容は、開いているブラウザの **localStorage** に保存されます。つまり：

- 同じブラウザ・同じ端末であれば、閉じても再度開いたときに内容が残ります
- **別の端末やブラウザとは同期されません**（あくまでその場所だけのローカル保存です）
- ブラウザの「閲覧データを削除」を実行すると消えるので注意してください

複数端末で同期したい場合は、別途サーバー同期の仕組み（Firebase等）を追加する必要があります。必要であれば相談してください。

## カスタマイズ

- アイコンの色や見た目を変えたい場合は `icons/` 内のPNGを差し替えてください（192×192、512×512、180×180の3サイズ）
- テーマカラーは `manifest.json` の `theme_color` と `index.html` 内の `<meta name="theme-color">` の両方を変更してください
